# 开发顺序清单

本清单是后续开发的执行顺序。每一项通过验收后再进入下一项，避免认证、渠道和资金授权边界相互混淆。

- [x] 1. MySQL 与 Alembic
  - Agent 会话、授权、审计和沙箱状态持久化。
  - 后端重启后可恢复待补槽任务。

- [x] 2. 用户身份基础
  - 建立 `users`、`password_credentials`、`auth_sessions`、`auth_events`。
  - 写入 `user_001`（林安）和 `user_002`（周宁）两个虚构用户。
  - 用户仅包含脱敏演示信息，密码凭据暂不写入。

- [x] 3. 业务数据绑定用户
  - 为账户、联系人、订阅、Agent Session、Run、确认、验证和审计增加用户归属。
  - 验收：`user_002` 无法读取或操作 `user_001` 的资源。

- [x] 4. 登录与密码安全
  - 使用 Argon2id 保存密码哈希。
  - 增加统一错误提示、失败计数、短时锁定和认证审计。
  - 两个演示账号已初始化，数据库仅保存 Argon2id 哈希，认证审计已验证。

- [x] 5. JWT Access Token
  - 10 分钟有效期，包含 `sub`、`sid`、`jti`、`iss`、`aud` 和令牌类型。
  - 验收：过期、篡改、错误签发方和错误类型均返回 401。
  - 本地 JWT 密钥与认证状态已验证，未认证访问正确返回 401。

- [x] 6. Refresh Token 与会话撤销
  - 随机 Refresh Token 只通过 HttpOnly Cookie 传输，数据库仅保存哈希。
  - 支持轮换、注销、全部设备下线和重放检测。
  - 代码、迁移、自动测试和本地登录/刷新接口验收均已完成。

- [x] 7. 后端接口鉴权
  - Agent、审计、确认和验证接口从认证上下文获取用户。
  - 不信任请求体中的用户 ID 或可猜测的 Session ID。
  - 验收：匿名访问返回 401，跨用户 Run、Session 和确认操作返回 403，审计按当前用户隔离。

- [x] 8. 前端登录与会话恢复
  - Access Token 只保存在内存。
  - 刷新页面通过 HttpOnly Refresh Token 恢复登录。
  - 支持 401 自动刷新并重试一次、单设备退出、全部设备下线和用户级本地会话隔离。
  - 验收：TypeScript 构建通过；浏览器模拟验证登录、页面刷新恢复、401 自动续期，存储中不存在 Access Token 和密码。

- [x] 9. Agent 会话归属改造
  - 后端为当前用户分配会话并校验所有权。
  - 验收：刷新和后端重启后仍能恢复，跨用户访问被拒绝。
  - 提供当前用户会话列表、最近会话恢复和新建会话；客户端伪造的未知会话 ID 返回 404。

- [x] 10. 红色操作 Step-up MFA
  - MFA 挑战绑定用户、Run、操作快照、过期时间和单次使用状态。
  - 随机六位码仅保存带密钥 HMAC 摘要，连续失败三次熔断，支持重发冷却和重放拒绝。
  - 本地演示取码接口要求 JWT 所有权且响应禁止缓存，非本地环境返回 404。

  - [x] 11.1 建立人物、事件、目标、关系边和定时动作的数据模型与迁移脚本。
  - [x] 11.2 实现 Repository、候选变更确认和用户级 API。

- [x] 14.2 主动生活事件雷达

  - 支持失败退避、人工处理、暂停、恢复、取消和沙箱模拟时间，并记录完整状态审计。

  - 使用 LangGraph 编排约束补充、时间线、方案选择、候选、二次确认、人工接管和撤销。
  - 候选阶段零写入；确认事务重读余额和目标，快照变化后旧方案失效并重新计算。
  - 前端提供目标约束、方案对比和逐日余额视图；比赛版 Consent Scope 强制关闭自动应用。
  - 详细实现、接口和验收见 [`FAMILY_FUNDING_NEGOTIATION.md`](./FAMILY_FUNDING_NEGOTIATION.md)。

- [x] 14.4 反诈冷静期
  - 使用用户域 HMAC 收款人指纹关联跨 Run、跨会话的改写重试，不保存原始聊天文本到风险事件表。
  - 高危语义组合创建 `COOLING_OFF` 事件；同一收款人重试被阻断，其他收款人不受影响。
  - 展示确定性事实证据、冷静期结束时间和 96110 求助入口；误报申诉不自动解除。
  - 仅受信 App JWT 可创建 MFA 释放挑战，飞书和其他 IM 无权解除；释放后原转账不自动恢复。
  - 策略节点和最终转账节点双重检查，覆盖并发重试、到期、跨用户隔离和旧授权失效。
  - 详细实现、接口和验收见 [`FRAUD_COOLING_PERIOD.md`](./FRAUD_COOLING_PERIOD.md)。

- [x] 14.5 家庭守护授权圈
  - 使用只存摘要的一次性定向邀请和双方确认建立守护关系，不从生活图谱自动推导权限。
  - Consent 明确限制场景、金额、可见字段和有效期；守护人只收到白名单风险摘要与金额区间。
  - 风险双确认强制本人先确认，守护人只能确认“风险已知”，不能满足 MFA 或授权资金执行。
  - 任一方可即时撤销；到期、越权、令牌重放和撤销后旧访问均默认拒绝并写入审计。
  - 前端支持两个演示账号完成邀请、接受、风险双确认和撤销，详细说明见 [`GUARDIAN_CIRCLE.md`](./GUARDIAN_CIRCLE.md)。

- [x] 14.6 渠道与绑定管理
  - 前端“渠道”工作区可生成飞书绑定码、显示剩余时间、复制绑定口令、查看脱敏身份并撤销。
  - 渠道身份只展示 HMAC 脱敏指纹和最近活跃时间，不向用户接口返回租户或原始外部 ID。
  - 长连接、Webhook 和生活雷达 Worker 使用数据库短租约心跳；进程停止后自动显示离线。
  - Webhook 在解析事件前校验签名、五分钟时间窗、Verification Token 并完成 AES-CBC 解密。
  - 平台重试继续使用 `channel_messages` 唯一约束、Agent 幂等键和飞书回复 UUID 三层防重。
  - 详细实现和部署边界见 [`CHANNEL_GATEWAY.md`](./CHANNEL_GATEWAY.md) 与 [`FEISHU_WEBHOOK.md`](./FEISHU_WEBHOOK.md)。
